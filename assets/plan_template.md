# Plan output template

Produce the plan as a single page in this order. Do not put the allocation before the health check — the reader needs to see why the numbers are what they are before seeing the numbers.

---

## 1. Assumptions used

State every figure that was assumed rather than supplied, and what changes if it is wrong. Mark assumptions as assumptions, in the first screen, not in a footnote.

| Assumption | Value | If wrong, re-run |
|---|---|---|
| Base currency | | bond and cash sleeves |
| Debt | | health check, risk level |
| Household composition | | emergency months, life cover |
| Insurance in force | | gap |
| Monthly essential spending | | emergency bucket |
| Monthly saving capacity | | every bucket |
